# Claudinha

**A terminal manager for Claude Code.** Run many Claude Code terminals side-by-side in one window, each in its own git worktree, with shared context and bulk actions. macOS, Windows, and Linux.

## Install

### Download (recommended)

Download the latest installer for your platform from the [Releases](https://github.com/scottdflorida/claudinha/releases) page:

| Platform | File |
|----------|------|
| macOS | `Claudinha-x.x.x.dmg` |
| Windows | `Claudinha-Setup-x.x.x.exe` |
| Linux | `Claudinha-x.x.x.AppImage` |

### npm (CLI launcher)

```bash
npm install -g claudinha
claudinha
```

---

## Usage

Launch the app, open a workspace (any project directory), and start as many Claude Code terminals as you need — each running an independent session in its own git worktree. Claudinha keeps them organized in a single window with shared settings and cross-terminal bulk actions.
